# Tarea 3: Lista de tareas

## Autor
Luis Ricardo Delgado Sevilla

## Descripción
Aplicación web que permite organizar actividades
personales, escolares y laborales.

## Funcionalidades
- Agregar, editar y eliminar tareas.
- Establecer fechas límite.
- Clasificar tareas por categorías.
- Mostrar tareas próximas a vencer.
- Cambiar entre modo claro y oscuro.
- Animación al eliminar tareas.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
