
# ☣ ZombieZone - Survival Games

## Descripción

ZombieZone es una aplicación web desarrollada con Vue.js
que permite explorar un catálogo de videojuegos de zombis
y supervivencia.

El propósito de esta aplicación es que los usuarios puedan
consultar videojuegos, guardar sus favoritos, calificarlos
y llevar un registro de su progreso de manera interactiva.

## Funcionalidades

- Catálogo de 9 videojuegos.
- Buscador de videojuegos en tiempo real.
- Filtro por plataforma.
- Filtro por estado del videojuego.
- Sistema de favoritos.
- Calificación de 1 a 5 estrellas.
- Registro de videojuegos pendientes, jugando y completados.
- Barra de progreso.
- Almacenamiento local mediante localStorage.
- Diseño adaptable a computadoras y dispositivos móviles.

## Tecnologías utilizadas

- Vue.js 3
- Vite
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Conceptos de Vue.js aplicados

- Reactividad mediante ref.
- Propiedades computadas mediante computed.
- Observadores mediante watch.
- Componentes reutilizables.
- Comunicación mediante props y emits.
- Manejo de eventos.
- Renderizado condicional.
- Renderizado de listas.
- Vinculación de datos mediante v-model.

## Instalación

Clonar el repositorio:

    git clone https://github.com/Luis-Ricardo-Delgado/Programacion-Web.git

Ingresar a la carpeta del proyecto:

    cd Programacion-Web/Trabajo-libre-6

Instalar las dependencias:

    npm install

Ejecutar la aplicación:

    npm run dev

Generar la versión de producción:

    npm run build
