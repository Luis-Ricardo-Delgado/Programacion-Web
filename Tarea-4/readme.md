# ChivaChat 🔴⚪🔵

## Autor
Luis Ricardo Delgado Sevilla

## Descripción
ChivaChat es una aplicación web de chat en tiempo real con temática de las Chivas del Guadalajara. Su objetivo es permitir que diferentes usuarios puedan comunicarse simultáneamente.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Node.js
- Express
- Socket.IO

## Objetivo
Conocer el funcionamiento de JavaScript del lado del servidor y la comunicación en tiempo real entre diferentes clientes.

## Instalación
npm install

## Ejecución
npm start

## Conclusión
Con esta actividad pude conocer cómo funciona un chat en tiempo real utilizando Node.js y Socket.IO, además de aplicar mis conocimientos de programación web en un proyecto con una temática de mi interés.
